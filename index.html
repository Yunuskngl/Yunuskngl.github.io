B.Sc. Mathematical Engineering

Jun 2026 Yıldız Technical University

Thesis: Cryptographic Key Management Vulnerabilities in Mobile Devices. Advisor: Assoc. Prof. Serkan Onar.

  • Examined the iOS Secure Enclave and Keychain from a mobile forensics and mathematical engineering perspective, testing how far they can be bypassed depending on the device’s lock state.
  • On an iOS 17 full file system image, showed that in the After First Unlock state the decryption keys remain in memory, so the Keychain can be fully decrypted.
  • In a case study on Signal Messenger, recovered its 256-bit SQLCipher key from the Keychain and read the full chat history in plaintext: security depends on key management, not only on strong algorithms.
